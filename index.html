YOUR GATEWAY. YOUR ENVIRONMENT.

Keep the application
close to the work.

The designer lives in a browser. The gateway lives with you. No application CDN or cloud account is required to run a prepared deployment.

01

Windows first

A self-contained Windows gateway with bundled Python. Build and operate through the local browser interface.

MAC SUPPORT PLANNED
02

A container, too

A Linux Docker baseline with a non-root runtime. Offline startup, local assets, and Python execution have been tested.

SELF-HOSTED GATEWAY
03

Ready to disconnect

Prepare the package or image on a connected machine, then transfer it. The application serves its own browser assets locally.

NO RUNTIME CDN DEPENDENCY

Air-gapped deployment needs advance preparation and validation on the target. Real connectors still need access to their configured local servers.

EARLY PREVIEW

A working foundation.
A clear view of what’s next.

SparkStudio is being built around practical internal applications. This preview is for trusted local development; authentication, permissions, and audit controls are still ahead.

Available to explore

Browser designer, operator runtime, interactive forms, reusable templates, saved-row repeaters, images, icons, popups, and gateway Python.

IMPLEMENTED
Connecting the data

Secured OPC UA client subscriptions verified locally on Windows. SQL Server reads are implemented, with live end-to-end validation pending.

IN VALIDATION
Further down the path

Identity and access control, broader platform features, macOS, and migration tooling. Native Ignition project import and full feature parity are not available.

ROADMAP

The current gateway is unauthenticated. Keep it on trusted local loopback for development; it is not ready for an exposed factory or shared network.
